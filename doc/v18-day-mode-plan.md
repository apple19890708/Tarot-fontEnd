# v18　白天模式（淺色主題）色彩規劃

建立日期：2026-11-07
狀態：進行中（階段 1～4 完成，待階段 5 逐頁檢查）

## 一、目標

現在全站只有一種深色版型（以下稱「黑夜模式」）。新增「白天模式」，讓白天、戶外、亮螢幕下看股市數字與長文（AI 解讀、新聞重點）不吃力，並保留塔羅工作室的像素、和紙質感。

**不做的事**

- 不重新設計版面、字級、元件形狀；只換顏色。
- 不為單一頁面另做專屬配色；全站共用一套語意色。
- 不改塔羅牌卡圖片、像素字型。
- 不改像素背景（星夜、街景、門口、店內）：白天模式也是同一套夜景，只換面板與文字的顏色。
- 不依時間自動切換（晚上自動變黑夜）；只跟系統設定或手動選。
- 不新增套件。

## 二、規格

### 2.1 做法：語意色變數，不用 `dark:` 前綴

現在的顏色直接寫在 class 裡（`bg-[#0f1526]`、`text-stone-300`、`border-white/10`、`text-amber-100`……），69 個檔案約 1,700 處。

- 在 `style.css` 用 Tailwind 4 的 `@theme` 定義一組**語意色**（例如 `bg-surface`、`text-ink`、`border-line`、`text-up`），值是 CSS 變數。
- 黑夜模式的變數值＝現在的顏色，所以**換成語意色後黑夜模式畫面完全不變**，可以分頁慢慢換、每換一頁就比對截圖。
- 白天模式只在 `<html data-theme="light">` 底下改寫同一組變數，元件不用寫兩套 class。
- 不採用 `dark:` 前綴：每個顏色要寫兩次、1,700 處會變 3,400 處，之後新增畫面很容易漏掉一邊。

### 2.2 語意色與兩種模式的色票

背景與文字：

| 語意色 | 用途 | 黑夜模式（現況） | 白天模式 |
| --- | --- | --- | --- |
| `page` | 整頁底色 | 漸層 `#120f1d → #0b1020` | 和紙底 `#efe6d2` |
| `surface` | 主要面板（大盤概況、股市追蹤外框） | `#0f1526` | 淺和紙 `#fbf6ea` |
| `raised` | 面板裡的卡片、輸入框 | `white/5` | `#f3ead6` |
| `line` | 一般框線、分隔線 | `white/10` | `#d8cbb0` |
| `frame` | 像素粗框、彈窗外框 | `#3b2618`（木色） | 同 `#3b2618`（保留木框，兩種模式的招牌） |
| `ink` | 標題、數字 | `stone-50` | 墨色 `#2a1a14` |
| `ink-soft` | 內文 | `stone-200` | `#44342a` |
| `ink-muted` | 標籤、日期、說明小字 | `stone-300`（最暗只到這） | `#5c4a3d`（最淺只到這，對淺底對比 ≥ 7:1） |

點綴與狀態（白天模式全部改用深一階的色，淺底上才看得清楚）：

| 語意色 | 用途 | 黑夜模式 | 白天模式 |
| --- | --- | --- | --- |
| `accent` | 金色重點（重點卡名稱、選中的分頁、主要按鈕字） | `amber-100／200` | 琥珀褐 `#8a5a12` |
| `accent-soft` | 重點卡底色 | `amber-200/6%` | `#f6e7c4` |
| `accent-line` | 重點卡框線 | `amber-200/25%` | `#d9b56e` |
| `up` | 漲（台股習慣紅） | `rose-300` | 朱紅 `#b42318`（和紙的 `#a8322a` 再深一點） |
| `down` | 跌（綠） | `emerald-300` | 深綠 `#1f6b45` |
| `up-soft`／`down-soft` | 語氣標籤、漲跌徽章的底 | `rose-300/10%`、`emerald-300/10%` | `#fbe3df`、`#dcefe3` |
| `info` | 降溫、說明（天藍） | `sky-200` | 靛藍 `#2f5d86`（和紙的 `#3d5a80` 系） |
| `warn` | 升溫（琥珀，不用紅綠） | `amber-200` | `#8a5a12`（同 accent） |
| `danger` | 錯誤訊息 | `rose-200` on `rose-300/10%` | `#9b1c1c` on `#fbe3df` |

所有白天模式的文字色對 `surface` 的對比都要 ≥ 4.5:1（小字 ≥ 7:1）；交付前用對比工具逐一量過，數值記在決議紀錄。

### 2.3 特殊元件

- **類股熱力圖**：黑夜是深紅／深綠底＋淺字。白天改成「漲越多越紅」的淺→深紅（`#fbe3df → #b42318`）、跌同理用綠；深色格用白字、淺色格用墨色字，切換點在色階中間。
- **圖表（Chart.js）**：`CHART_COLORS` 改成兩套，畫圖時讀目前的模式；切換模式時圖表要重畫。格線、軸字、成交量柱在白天改用墨色的低透明度。均線色（金、粉、藍）白天換成深一階（`#b7791f`、`#c2410c`、`#2f5d86`）。
- **像素陰影**：`shadow-[6px_6px_0_rgba(0,0,0,0.5)]` 白天改成木色淡陰影 `rgba(59,38,24,0.25)`，一樣是不模糊的像素陰影。
- **和紙區塊**（我的紀錄左欄、`SelectField` washi）：本來就是淺色，白天模式維持原樣，和整頁融為一體。
- **彈窗遮罩**：黑夜 `black/70`，白天 `#2a1a14/40%`。
- **`color-scheme`**：跟著模式切換，讓瀏覽器原生的捲軸、日期選擇器也變色。

### 2.4 切換方式

- **預設黑夜**：第一次進站一律是黑夜模式（不跟系統設定），品牌是星夜工作室；手動選過就記在 localStorage（這台裝置有效，不存到帳號）。
- **切換放在右上角的水晶球選單（`FloatingMenu`）裡**，和「牌面風格」同一種選項樣式（日／夜兩個選項，搭太陽、月亮像素圖示），不在頁首另加按鈕。
- 水晶球目前只在看得到牌的頁面出現（`App.vue` 的 `showFloatingMenu`：占卜結果第 3 步、我的紀錄）。改成**全站都顯示**；選單內容依頁面決定：「日夜」每頁都有，「牌面風格」「跳到段落」維持原本出現的條件。
- 水晶球在原本沒有它的頁面（股市追蹤、會員、管理頁）會浮在右上角：要檢查有沒有蓋住各頁右上的按鈕（例如大盤概況的「更新」），蓋到就讓內容讓位，做法參考個股分析彈窗標題列右邊留空。
- 在 `index.html` 的 `<head>` 先讀設定再顯示畫面，避免載入時先閃一下黑夜再變白天。

### 2.5 像素背景（不動）

星夜、街景、門口、店內是 canvas 畫的夜景，兩種模式共用，不做白天版。白天模式的淺色面板疊在夜景上（店內木牆本來就是暖色，搭和紙面板不衝突）；只有背景壓暗的程度可以在階段 5 實際看過後微調。
