# 工作週記（前端）2026-11-16 ～ 2026-11-22

## 2026-11-17

### 帳戶會員安全與 SEO（計畫書在後端 `doc/v24-account-security-plan.md`）

#### 帳號安全（配合後端階段 1、2）
- Google 登入後如果後端回 `passwordCleared`（信箱沒驗證過的舊密碼被停用），跳一個只有「確定」的提示框說明原因；`confirmDialog` 新增 `alert`（不顯示取消）。
- 新頁面「帳號設定」`/account`（`AccountView.vue`）：從導覽列點自己的名字進入。顯示信箱與登入方式、改密碼（只有 Google 的帳號改成指向忘記密碼）、登出所有裝置、刪除帳號（密碼帳號輸入密碼；Google 帳號重新用 Google 登入確認；管理者不能刪）。刪除與全部登出都先用 `confirmDialog` 確認。
- `GoogleSignInButton` 新增 `divider`（帳號設定頁不顯示「或」分隔線）。
- 管理頁會員詳細資料顯示今天的塔羅 AI 解讀與追問次數（舊版後端沒有就不顯示）。
- 隱私權頁的「刪除資料」改成指向帳號設定頁，保留聯絡信箱當備用。

#### SEO（階段 4）
- 網站名稱改成 Tarot Bar、標語「小酌一杯，抽一張牌」：`index.html` 的標題、描述、canonical、Open Graph、Twitter 標籤；`manifest.webmanifest` 的名稱。
- 分享預覽圖 `public/og-image.png`（1200×630，像素風馬丁尼插半片橘子＋「Tarot Bar」），原稿 `doc/og-image.svg`。
- 文案集中在 `src/seo.json`；換頁時 `src/lib/seo.ts` 更新標題、描述、canonical，要登入的頁與忘記／重設密碼頁加 `noindex`（路由 `meta.noindex`）。
- `npm run build` 最後多跑 `scripts/seo-pages.mjs`：換上完整網址、產生 `login/`、`register/`、`privacy/` 各一份 HTML（直接開子頁回 200，不再靠 404.html）、`sitemap.xml`。

#### 階段 3
- 信箱驗證：新頁 `/verify-email`（點驗證信的連結，不需登入）；註冊後提示去收信；帳號設定頁顯示驗證狀態與「重寄驗證信」；管理頁會員詳細資料標示「信箱未驗證」（不能開通 AI／股市）。
- 管理者只能用 Google 登入：登入頁直接顯示後端的提示，前端不用改。
- CSP：`scripts/seo-pages.mjs` 打包後在每份 HTML 加 `<meta http-equiv="Content-Security-Policy">`，內嵌腳本自動算 sha256，API 來源讀 `VITE_API_BASE_URL`。無頭 Chrome 載入首頁、登入、隱私權沒有 CSP 違規。
- 左上角改成「小酌一杯，抽一張牌／Tarot Bar」。
- 規範：`dev-server` 補一條「看打包結果不要用 vite preview」（preview 的 base 是 `/`，JS 回成 HTML、畫面空白，差點誤判成 CSP 擋掉）。
