# 寫前端工作紀錄

檔案：`doc/worklog.md`，繁體中文，最新日期**附加在檔尾**。

## 格式

```markdown
## YYYY-MM-DD

### <主題>
- 畫面或互動改了什麼
- 新增／修改的型別與 API 呼叫

### 其他
- 驗證：`npm run build` 通過

### 待辦
- 還沒做完的事
```

## 要點

- 日期用今天的實際日期，不要寫相對時間。
- 寫**使用者看得到的改變**與原因，不要抄 diff。
- 依賴後端新欄位時，註明該欄位是可選的、舊版後端的退路是什麼。
- 若今天的日期區塊已存在，補在該區塊底下。
- 不要把 `.env*` 的值寫進紀錄。
