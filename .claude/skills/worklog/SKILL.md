# 寫前端工作週記

一週一個檔：`doc/worklog/<該週週一的日期>.md`，繁體中文。週一到週日算同一週。

## 找到這週的檔案

1. 依今天的實際日期算出這週的週一（例：2026-10-28 是週三，週一是 2026-10-26）。
2. `doc/worklog/2026-10-26.md` 已存在：最新日期**附加在檔尾**。
3. 不存在：新建這個檔，第一行寫標題，週日的日期要算出來：

   ```markdown
   # 工作週記（前端）2026-10-26 ～ 2026-11-01
   ```

## 每天的格式

```markdown
## YYYY-MM-DD

### <主題>
- 畫面或互動改了什麼
- 新增／修改的型別與 API 呼叫

### 其他
- 驗證：`npm run build` 通過

### 待辦
- 還沒做完的事
```

## 要點

- 日期用今天的實際日期，不要寫相對時間。
- 寫**使用者看得到的改變**與原因，不要抄 diff。
- 依賴後端新欄位時，註明該欄位是可選的、舊版後端的退路是什麼。
- 若今天的日期區塊已存在，補在該區塊底下。
- 新的一週開檔時，把上週還沒完成的「待辦」搬到新檔第一天的待辦裡，舊檔不用改。
- 不要把 `.env*` 的值寫進紀錄。
